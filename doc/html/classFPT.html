PFILE FPT::ffopen ( const STRING & FileName,
const CHR * Type )

Opens FileName in the given mode, reusing a cached handle if this table already has FileName open in the same mode.

Parameters
FileNameFile to open.
Typefopen()-style mode string ("r", "w", "a", ...).
Returns
The (possibly cached) FILE*, or nullptr on a genuine fopen() failure once every cache path has been exhausted.

Evicts the table's least-recently-touched entry if it's already at MaximumEntries capacity. The evicted entry is only physically fclose()'d if it was already logically closed (GetClosed()) – otherwise its FilePointer is silently overwritten below without being closed, a known leak when every cached entry is still logically open at eviction time (see docs/BUG_CATALOG.md).
