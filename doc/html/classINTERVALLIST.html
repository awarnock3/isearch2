Detailed Description

Owns a heap-allocated, growable table of INTERVALFLD entries used for numeric-interval range search. Non-copyable, matching NUMERICLIST above: no live call site ever copies one (see BUGFIX #1), so the copy constructor and operator= are both deleted rather than given deep-copy semantics.
