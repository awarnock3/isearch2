Detailed Description

A GCMD/DIF (Directory Interchange Format) DOCTYPE: "Fieldname: value" / "Group: name ... End_Group" text, parsed by a small hand-written recursive-descent parser (start()/atom()/field()/ group()/... below, implementing the grammar in the file-level doc comment in dif.cxx) driven by a character-at-a-time scanner (sgetc()/sungetc()/tell()) over RecBuffer. See dif.cxx for the grammar and RecBufferLen's role in keeping the scanner in bounds.

Loads the FIELDTYPE file (the -o fieldtype=<filename> doctype option) into Db->FieldTypes, one "FIELDNAME TYPE" entry per line.

Reads the whole file into memory and tokenizes it with strtok() on newlines. If no FIELDTYPE option was given, or the named file can't be opened, logs a message and returns with every field left to default to type "text" (see writeField()).

◆ nextToken()

enum DIF::TokenType DIF::nextToken ( )

Retrieves the next token per the scanner's DFA; stores its text in token.

Retrieves the next token from the input stream, per the small DFA above (states 0-4, keyed off DIF::state): state 0 is "between fields," expecting a field name, "Group:", or "End_Group"; state 1 reads the group name after "Group:"; state 2 is inside a group, expecting another field/group/End_Group, or — for the fixed set of multi-line group names in multilineGroup[] — free text via readNewLine(); state 3 reads a field's value as one line of text; state 4 reads successive lines of multi-line group text until End_Group. Stores the token's text in the token member.

Returns
The type of token found (see DIF::TokenType), or errorType if state is out of range.

Parses a DIF START_DATE/STOP_DATE range into fStart / fEnd.

Parses a DIF date range ("START_DATE: ... \n STOP_DATE: ...") into fStart / fEnd.

Searches Buffer (uppercased, dashes stripped) for the "START_DATE: " and "STOP_DATE: " labels independently. A missing START_DATE is an error for the whole range (both outputs set to DATE_ERROR); a missing STOP_DATE defaults to DATE_PRESENT (an open-ended range). Year/month-only values are promoted to a full day boundary (start of year/month for fStart, end for fEnd) via SRCH_DATE::PromoteToDayStart()/PromoteToDayEnd().

Parameters
BufferText containing the START_DATE/STOP_DATE labels.
fStartReceives the parsed start date, or DATE_ERROR/ DATE_UNKNOWN.
fEndReceives the parsed end date, DATE_PRESENT if absent, or DATE_UNKNOWN.

Reimplemented from DOCTYPE.

◆ ParseFields()

void DIF::ParseFields ( PRECORD NewRecord)

Parses a record's fields via the recursive-descent parser and attaches the resulting DFT.

Reads NewRecord's bytes off disk into RecBuffer, runs the recursive-descent parser (start()) over them, and attaches the resulting field table (DFT) to NewRecord.

Adds one DF entry per matched field, each with the byte-offset range (start, end) of its value within the record. RecBufferLen is set here, right after RecBuffer is allocated and NUL-terminated — see sgetc()'s doc comment for how the scanner uses it to stay in bounds.

Parameters
NewRecordRecord to parse and attach field data to. A nullptr is a silent no-op.
