Detailed Description

Splits a search-query string into tokens (words, quoted literals, {...} groups, and the ( ) !/&& ||-family operator tokens), lazily parsed on first use (see DoParse()). Non-copyable: no live call site ever copies one (see BUGFIX #1), so the copy constructor and operator= are both deleted rather than given deep-copy semantics.
