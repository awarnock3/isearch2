36/*@Doc: The {\em HASH} class implements a simple memory-based hash table
37using open-addressed quadratic probing. As with any open-addressed hash
38method, the hash table must be large enough to contain every entry, and
39there must be no duplicate keys.
40
41We handle the entry count problem by returning a status tha tindicates
42whether or not an insertion occurred. Insertion failure is not an error
43condition in our Isearch application, so we simply flag it.
44
45The default hash table size is 997.
46
47The hash item contains a key, a state variable, and a pointer to a block
48of data. The data blocks must be dynamically allocated using {\bf
49malloc()} as they are free'd in the hash table destructor. The {\bf
50State} variable contains the following information:
51
52\begin{center}
53\begin{tabular}{ll} {\bf Value} & {\bf Meaning} \\
54\hline
550 & Empty Slot\\
561 & Filled Slot \\
572 & Deleted Slot - Continue Probe
58\end{tabular}
59\end{center}
60
61Note: no public method currently sets State to 2 (there is no
62Delete/Remove) -- the tombstone case above is real probing logic
63{\em Insert}/{\em Find}/{\em Check} all handle, but it's presently
64unreachable in this codebase.
65
66*/
