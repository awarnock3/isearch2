Detailed Description

Owns a heap-allocated, growable table of TH_PARENT entries. Grows automatically in AddEntry() when full (see BUGFIX #1). Non-copyable: no live call site ever copies one, so the copy constructor and operator= are both deleted rather than given deep-copy semantics.
