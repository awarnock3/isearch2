Detailed Description

One index-merge participant: wraps a sorted run of GP/key entries read from disk (list/Start/sistrings/Tag, all owned, heap-allocated arrays) and hands them out smallest-first via Smallest()/Load() during an N-way merge. Non-copyable: no live call site ever copies one (see BUGFIX #1), so the copy constructor and operator= are both deleted.
