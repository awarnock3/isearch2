Detailed Description

Implementation of the Field Coordinate Table (FCT) class.

Provides the implementation for FCT, an ordered circular list that manages field coordinate pairs. The FCT class inherits from VLIST to maintain a doubly-linked list structure. Supports operations such as adding entries, retrieving coordinates, sorting by field start position, and serialization to/from text format. Field coordinates track the byte positions of indexed term occurrences within document fields, enabling precise field-based searching and result highlighting.
