30// ParseFields() walks HTML <tag>value</tag> pairs (delegating the

34// applying a hand-rolled fallback for the common "minimized tag" HTML
35// idioms (<DD>/<DT>/<LI>/<TL> used without a matching close). Present()
36// with BRIEF_MAGIC ("B") returns the "title" field, falling back to
37// the filename if there is none.
