65// The Multiple Document Table: one entry per indexed document, backed
66// by an on-disk .mdt record file plus two in-memory sort indexes
67// (KeyIndex, GpIndex) mirrored to .mdk/.mdg on FlushMDTIndexes().
68class MDT {
69public:
70 MDT(const STRING& DbFileStem, const GDT_BOOLEAN WrongEndian);
71 // BUGFIX #1: MDT owns two heap-allocated arrays (KeyIndex, GpIndex)
72 // and a raw FILE* (MdtFp), but declared no copy constructor and no
73 // operator= at all -- not even a hand-written one -- so the
74 // compiler-generated ones did a member-wise shallow copy of all
75 // three. Confirmed to double-free GpIndex under ASan (one level
76 // inside FlushMDTIndexes() -> SortGpIndex() -> qsort()); the shared
77 // MdtFp would double-fclose() by the same mechanism. Made
78 // explicitly non-copyable rather than deep-copied: nothing in the
79 // tree copies an MDT by value today, and there's no well-defined
80 // answer for what a copy of an open file handle should mean. See
81 // docs/BUG_CATALOG.md.
82 MDT(const MDT&) = delete;
